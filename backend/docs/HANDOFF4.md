## 4. 必须遵守的约定

1. 后端原始字段严禁改动：`seatId` / `roomId` / `reserveDate` / `slot` / `status` / `canCheckin` / `canCancel`。
2. 座位状态每次切换日期时段必须重新请求接口，前端不做本地缓存。
3. 日期时间全部原样传递后端字符串，禁止前端转为时间戳。
4. 所有枚举（时段、座位状态）均从`/api/meta/*`拉取，禁止硬编码文字与数字。
5. 409类业务冲突报错后必须刷新座位数据；500类服务异常仅弹出文字提示，不刷新页面。
